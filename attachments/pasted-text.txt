# 205. ADVANCED INTERPRETATION AND PREDICTION METHODOLOGY

The following section defines **how the fetched data should actually be interpreted**, transformed into predictive signals, combined mathematically, and converted into BTTS, Over/Under, 1X2 and Correct Score probabilities.

The implementation must not simply count historical percentages.

The engine should infer a latent pre-match state:

```text
ATTACK QUALITY
DEFENSIVE QUALITY
HOME/AWAY EFFECT
RECENT FORM
SQUAD AVAILABILITY
TACTICAL/LINEUP STATE
GOAL ENVIRONMENT
MARKET STATE
UNCERTAINTY

Then estimate:

lambda_home
lambda_away

and derive the four markets from the joint score distribution.

Football score models in the literature commonly use Poisson-family models, while Dixon-Coles specifically adjusts low-score outcomes and later work has explored dynamic/state-space, bivariate and overdispersed models. [8][9]

206. RAW DATA MUST NEVER ENTER THE FINAL MODEL UNTRANSFORMED

The engine should implement:

RAW API DATA
      ↓
VALIDATION
      ↓
NORMALIZATION
      ↓
TEMPORAL FILTER
      ↓
CONTEXT FILTER
      ↓
RECENCY WEIGHTING
      ↓
SHRINKAGE
      ↓
OPPONENT ADJUSTMENT
      ↓
FEATURE ENGINEERING
      ↓
LATENT TEAM STATE

Example:

raw:
14 shots

do NOT directly interpret:
"14 shots = strong attack"

Instead:

14 shots
→ opponent-adjusted shots
→ home/away-adjusted shots
→ recent weighted shots
→ shot-volume percentile
→ relationship to SOT
→ relationship to goals
→ relationship to opponent defensive allowance
→ uncertainty estimate
207. FOUR-STEP DATA INTERPRETATION ENGINE

Every feature should pass through four questions.

Question 1 — WHAT HAPPENED?

Question 2 — AGAINST WHOM?
Opponent defensive strength
Question 3 — IN WHAT CONTEXT?
home matches?

competition?
recent?

Question 4 — HOW RELIABLE IS IT?
sample size
variance

recency

Only after these four questions should the feature enter the prediction model.

208. SIGNAL → EVIDENCE → LATENT STATE

The engine should distinguish three levels.

OBSERVATION

EVIDENCE

LATENT STATE

209. ATTACK STRENGTH INTERPRETATION

Build a composite attack state:

+

+

+

+

attack_signal = (

    + w_shots * z(shots_adjusted)
    + w_sot * z(sot_adjusted)
    + w_consistency * z(scoring_consistency)
)
